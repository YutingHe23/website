# Yuting He — personal homepage

This is an independent static homepage, prepared for the `YutingHe20/YutingHe` GitHub Pages site and kept outside the paper-sync repository.

Open `index.html` directly or serve the directory with:

```bash
python3 -m http.server 8000
```

The page uses only `index.html` and `style.css`, so it can be copied into a new repository without a build step.
